# 公开版内容处理

本目录由允许公开的文件单独组装，未复制私人照片目录、私人家庭水彩头像、个人信件、录音、参考照片、历史文档、截图、备份、交付记录或 Git 历史。

欢迎页、木马、挂画、电视及信件插图使用四幅虚构涂鸦。电话改成明显的演示号码，日历改为示例日期，私人家庭叙述改为通用祝福和动物旁白。门框装饰改为程序绘制的通用春联。

照片浏览器存储使用独立的 public-doodle-house-photos-v1 名称，不读取礼物版保存的照片。源码构建脚本使用项目依赖，不包含制作者电脑的绝对路径。

房屋布局和通用交互继续保留。所有示例图片都在目录内，分享时发送完整目录或完整压缩包即可。
